# 寻潮记小程序接口文档

> 版本：V1.2  
> 日期：2026-09-13  
> 产品：微信小程序「寻潮记」（原「观潮」）  
> 原则：**游客能把主路径走完**；登录只为同步进度、提高配额、写敏感操作。社区已下线。图鉴卡不再作为「观潮记录」。  
> V1.2 变更：新增签到 `POST /records/checkin` 与首页活动 `GET /activities`；补充修改昵称 `POST /me/nickname`、头像上传 `POST /me/avatar`；同步「我的服务」新信息架构、出门建议前端过滤口径与实际生产域名。

## 1. 约定

### 1.1 环境

| 环境 | Base URL（示例） |
| --- | --- |
| 开发 | `http://<host>:8000/api/v1` |
| 预发布 | `https://pre-api.example.com/api/v1` |
| 生产 | `https://api.example.com/api/v1` |

合法域名需在小程序后台配置。生产环境禁止 IP / localhost。

当前实际生产 Base URL 为 `https://www.blueakaiwu.cn/api/v1`（必须带 `www`）。静态图片走同域 `GET /static/assets/*`，规则见《图片资源接入说明》。

### 1.2 请求头

```http
Content-Type: application/json
Authorization: Bearer <accessToken>   // 有则带，游客可省略
X-Request-Id: <uuid>
X-Client-Id: <c_设备匿名ID>            // 必带。小程序本地生成，登录前后不变
```

游客请求**不得**因缺少 `Authorization` 返回 `40101`。用 `X-Client-Id` 识别同一台设备上的观潮记录、点亮进度、识别配额。

登录后：同一 `X-Client-Id` 上的游客数据合并进账号，只合并一次。

### 1.3 统一响应

成功：

```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "requestId": "b6c1e2f0-8a11-4c22-9d33-111111111111"
}
```

失败：`code` 非 0，`data` 为 `null`。分页：`list`、`page`、`pageSize`、`total`。

时间一律 ISO 8601，时区 `Asia/Shanghai`，例如 `2026-09-08T19:00:00+08:00`。

### 1.4 鉴权

| 标记 | 含义 |
| --- | --- |
| 游客 | 不登录可调用；有 token 时返回个性化字段 |
| 登录 | 必须有效 `accessToken` |
| 可选登录 | 无 token 按设备；有 token 按用户 |

Token 建议 2 小时过期，用 `refreshToken` 续期。微信 `code` 只允许后端换 `openid`。

### 1.5 错误码

| code | HTTP | 含义 |
| --- | --- | --- |
| 0 | 200 | 成功 |
| 40001 | 400 | 参数错误 |
| 40002 | 400 | 文件类型/大小不合法 |
| 40101 | 401 | 未登录或 token 失效（仅限「登录」接口） |
| 40301 | 403 | 未完成监护人同意 |
| 40302 | 403 | 无权访问 |
| 40401 | 404 | 资源不存在 |
| 40901 | 409 | 业务冲突 |
| 42901 | 429 | 限流 |
| 50001 | 500 | 服务器错误 |
| 50002 | 503 | 潮汐/天气超时，已降级 |
| 50003 | 503 | AI 不可用 |
| 50004 | 422 | 内容安全未通过 |

写接口支持 `Idempotency-Key`。相同 key 10 分钟内返回首次结果。

### 1.6 限流（建议）

| 能力 | 游客（按 IP + Client-Id） | 已登录 |
| --- | --- | --- |
| 读接口 | 60 次/分钟 | 120 次/分钟 |
| 上传（识别照片/头像） | 6 次/天 | 20 次/小时 |
| 研学报到签到 | 5 次/天 | 5 次/天 |
| AI 物种猜测 | 3 次/天 | 8 次/天 |
| AI 潮汐建议 | 首页缓存；手动刷新 1 次/5 分钟/地点 | 同左 |
| 观潮开始/结束 | 8 次/天 | 20 次/天 |
| 点亮地图上报 | 30 次/小时 | 60 次/小时 |

超限 `42901`，带 `Retry-After`。

### 1.7 游客能做什么

游客打开小程序后，不登录也应能：

1. 看首页、赶海点、潮汐表、潮汐日历、图鉴、知识科普、装备、帮助、协议  
2. **开始 / 结束观潮**，在「观潮记录」里看到文字记录  
3. **拍照识别**（配额更严），识别结果写入进行中的观潮  
4. 看出门建议  
5. 打开点亮地图、换地图、用定位点亮区块  
6. 看成就墙（未解锁为锁定态）和公开排行榜  
7. 在「我的服务 → 签到」用姓名 + 学号 + 约300米精度位置完成研学报到  

需要登录的：勋章分享回执、意见反馈、监护人同意、注销、账号级进度合并。

未满 14 周岁且 `needGuardianConsent=true`：浏览类仍开放；上传、识别、点亮上报、观潮写入返回 `40301`。

## 2. 功能 × 接口对照

当前三个 Tab：首页 / 成就 / 我的。社区已删除。「我的」页 = 观潮记录横幅 + 我的服务网格（潮汐表 / 潮汐日历 / 海洋图鉴 / 知识科普 / 成就 / 装备推荐 / 签到 / 常见问题 / 关于我们 / 设置）+ 合规文档链接；首页工具箱已迁入「我的服务」。

| 界面 | 游客怎么用 | 接口 |
| --- | --- | --- |

| 赶海地点推荐 / 全部 | 列表+详情弹窗 | `GET /spots`、`GET /spots/{id}`、`GET /home/today?spotId=` |
| 潮汐表 | 换地点、看曲线 | `GET /home/today`、`GET /spots` |
| 潮汐日历 | 按月 | `GET /tide/calendar` |
| 海洋图鉴 | 分类浏览+详情 | `GET /encyclopedia`、`GET /encyclopedia/{id}` |
| 知识科普 | 列表+详情 | `GET /knowledge`、`GET /knowledge/{id}` |
| 搜索 | 点位+生物 | `GET /search` 或同时调 spots / encyclopedia（`keyword`） |
| 成就墙 | 公开勋章+个人进度 | `GET /achievements/overview`、`GET /medals`、`GET /medals/{id}` |
| 继续探索 | 点亮地图 | `GET /light-maps`、`GET /light-maps/{id}`、`POST /light-maps/{id}/visits` |
| 排行榜 | 公开榜 | `GET /achievements/leaderboard` |

| 打卡统计 | 可选 | `GET /records/checkins` |

图鉴卡 `/cards*` 不再被前端调用（观潮记录走 `/watch/*`），可废弃。

## 3. 登录与用户

### 3.1 微信登录

`POST /auth/wechat-login`  
游客可调。

```json
{ "code": "wx_login_code", "clientId": "c_xxx" }
```

`clientId` 建议与头里 `X-Client-Id` 一致，用于合并游客数据。

响应：`accessToken`、`refreshToken`、`expiresIn`、`user`（`id`、`nickname`、`avatarUrl`、`level`、`title`、`needGuardianConsent`）。

不默认索取微信昵称、头像、手机号。默认昵称可用「寻潮探索者」。

### 3.2 刷新

`POST /auth/refresh`  
`{ "refreshToken": "rt_xxx" }`

### 3.3 当前用户

`GET /me`  
登录。

```json
{
  "id": "u_10001",
  "nickname": "寻潮探索者",
  "avatarUrl": "https://cdn.example.com/avatar/crab-cloud.png",
  "level": 24,
  "title": "海洋探索家",
  "score": 236,
  "total": 320,
  "stats": { "checkinCount": 12 }
}
```

社区相关计数（获赞/粉丝/收藏笔记）已删除，不要再返回。

### 3.4 修改昵称

`POST /me/nickname`  
登录。

```json
{ "nickname": "赶海小达人" }
```

昵称 1–20 字，去首尾空格，做内容安全（未通过 `50004`）。返回更新后的 `user`。编辑资料页与登录后设置昵称都走此接口。

### 3.5 修改头像

`POST /me/avatar`  
登录。`multipart/form-data`，文件字段名 `file`（前端 `wx.uploadFile` 直传，上传前已压缩）。

限制：jpg/png/webp，≤ 5MB；去 EXIF；过内容安全（未通过 `50004`）。响应：

```json
{ "avatarUrl": "/users/u_10001/avatar" }
```

`avatarUrl` 可为相对路径，前端会拼 Base URL 后通过 `GET /users/{userId}/avatar` 渲染（该接口不需鉴权）。

### 3.6 注销

`POST /me/delete`  
登录。删除学习记录、照片、观潮记录、点亮进度及 COS 对象。

## 4. 首页与潮汐

### 4.1 今日首页

`GET /home/today`  
游客。

Query：`city`、`spotId`、`lat`、`lng`、`date`（`YYYY-MM-DD`）。

进入首页不要强制定位。赶海推荐在用户授权后再带 `lat/lng`。

首页主按钮已改为「开始观潮」，**不要**再把 `advice` 或潮高写死在按钮上方。潮汐数据仍要返回，供潮汐表、出门建议、识别使用。

响应：

```json
{
  "place": {
    "spotId": "spot_qd_shilaoren",
    "name": "青岛 · 石老人",
    "city": "青岛"
  },
  "tide": {
    "source": "官方潮汐数据供应商名称",
    "updatedAt": "2026-09-08T08:50:00+08:00",
    "currentHeightM": 0.8,
    "trend": "falling",
    "points": [
      { "time": "06:20", "heightM": 0.3, "type": "low" },
      { "time": "12:10", "heightM": 1.9, "type": "high" }
    ]
  },
  "weather": {
    "text": "多云",
    "tempC": 24,
    "windScale": 3,
    "windDir": "东南",
    "waveHint": "轻浪"
  },
  "advice": {
    "headline": "现在正在退潮，适合看礁石",
    "body": "当前潮高约 0.8 米，正在退潮。请关注下一次涨潮时间。",
    "suitableNow": true,
    "suitableForLowerGrade": true,
    "leaveBefore": "16:00",
    "nextChange": { "time": "16:20", "type": "rising", "label": "开始涨潮" },
    "weatherLine": "今天多云、东南风 3 级、轻浪。",
    "safetyLine": "请由大人陪同；不要独自下水。",
    "disclaimer": "潮汐与天气仅供参考，请以海洋预报和现场管理为准。",
    "generatedBy": "ai",
    "fallback": false
  }
}
```

`trend`：`rising` | `falling` | `high` | `low` | `unknown`。

潮汐建议规则：只输入潮汐、天气、点位适龄/安全、当前时间。禁止姓名、学校、精确住址。失败时 `fallback=true` 用模板。必须带 `disclaimer`。

### 4.2 刷新出门建议

`POST /ai/tide-advice`  
游客。

```json
{ "spotId": "spot_qd_shilaoren", "date": "2026-09-08" }
```

响应同 `/home/today.advice`。

前端消费口径（V1.2 起）：

1. `body` 会按句过滤展示，天气、穿戴、泛化叮嘱类句子不显示——请让 `body` 只保留潮汐状态与赶海时机相关内容；
2. 涨/退潮时间点优先用 `nextChange`，缺失时前端从首页 `tide.points` 兜底计算——`nextChange` 请稳定返回；
3. `suitableNow=false` 时弹窗显示黄色「今日不太适合赶海」态。

### 4.3 潮汐日历

`GET /tide/calendar`  
游客。

Query：`spotId`、`month=2026-09`

```json
{
  "spotId": "spot_qd_shilaoren",
  "month": "2026-09",
  "days": [
    {
      "date": "2026-09-08",
      "lowTimes": ["06:20"],
      "highTimes": ["12:10", "18:40"],
      "observeHint": "上午退潮较适合观察"
    }
  ]
}
```

### 4.4 首页活动轮播

`GET /activities`  
游客。对应首页底部自动滑动的活动横幅（约 3.5 秒切换）。

```json
{
  "list": [
    {
      "id": "act_science_09",
      "tag": "科普",
      "title": "潮间带科普课",
      "desc": "认识小螃蟹和贝类朋友",
      "theme": "teal",
      "image": "https://www.blueakaiwu.cn/api/v1/static/assets/home/home-fish.png",
      "url": "/pages/knowledge/knowledge"
    }
  ]
}
```

字段容错：`tag` 可用 `category`，`title` 可用 `name`，`desc` 可用 `subtitle` / `summary`，`image` 可用 `imageUrl`，`url` 可用 `linkUrl`。

口径：

1. `theme` 仅 `teal` | `yellow`，只决定横幅配色，默认科普=teal、研学=yellow；
2. `image` 建议返回静态资源完整 URL；
3. `url` 为空或非 `/pages/` 开头时，前端点击提示「活动即将开放，敬请期待」；
4. 无数据 / 请求失败时前端用「科普 / 研学」两条本地默认兜底，不报错。

## 5. 赶海点

### 5.1 列表

`GET /spots`  
游客。

Query：`city`、`keyword`、`lat`、`lng`、`page`、`pageSize`

首页「赶海地点推荐」取热度前三。列表需能按 `heat` 排序。

```json
{
  "list": [
    {
      "id": "spot_qd_shilaoren",
      "name": "石老人",
      "city": "青岛",
      "heat": 96,
      "latitude": 36.0932,
      "longitude": 120.4768,
      "distanceM": 2300,
      "coverUrl": "https://cdn.example.com/spots/shilaoren.jpg",
      "photos": ["https://cdn.example.com/spots/shilaoren.jpg"],
      "openTime": "全天，以现场管理为准",
      "ageHint": "建议小学中高年级，需成人陪同",
      "safetyTags": ["礁石湿滑", "注意涨潮"],
      "observeHint": "退潮后适合观察牡蛎、藤壶、海藻",
      "species": [
        { "name": "藤壶", "id": "sp_barnacle" },
        { "name": "牡蛎", "id": "sp_oyster" }
      ]
    }
  ],
  "page": 1,
  "pageSize": 20,
  "total": 8
}
```

`latitude` / `longitude` 是点位中心，给前端算距离用，不是用户轨迹。拒绝定位时只按 `city`。

### 5.2 详情

`GET /spots/{spotId}`  
游客。

在列表字段上增加：`description`、`gearList`、`source`、`reviewedAt`、`photos[]`。

### 5.3 装备

`GET /gear`  
游客。按场景分组：`rocky` | `mudflat` | `sandy`。

```json
{
  "list": [
    {
      "name": "防滑鞋",
      "why": "礁石有海藻，很容易滑。",
      "scene": "rocky",
      "mustHave": ["rocky"]
    }
  ]
}
```

### 5.4 综合搜索

`GET /search`  
游客。Query：`keyword`（必填）、`page`、`pageSize`

```json
{
  "spots": { "list": [], "total": 0 },
  "species": { "list": [], "total": 0 }
}
```

无此接口时，前端会并行调 `/spots?keyword=` 与 `/encyclopedia?keyword=`。

## 8. 上传

拍照识别先走上传。用户点击后才调相机。

### 8.1 申请凭证

`POST /uploads/credential`  
游客（绑定 `X-Client-Id`）。登录后绑定用户。

```json
{ "scene": "speciesGuess", "contentType": "image/jpeg", "ext": "jpg" }
```

`scene`：`speciesGuess` | `observation`（不再使用 `card` / `community`）。

响应：`uploadId`、`objectKey`、`host`、`headers`、`expiresIn`。

限制：jpg/png/webp，≤ 5MB。去 EXIF。对象私有。

### 8.2 完成

`POST /uploads/{uploadId}/complete`  
游客。触发压缩、去 EXIF、内容安全。未通过 `50004`。

`status`：`processing` | `approved` | `rejected`

## 9. AI 物种猜测

口径：**猜测 + 图鉴对照**，禁止「已识别为某某」。

前端文案：标题「小螃蟹猜一猜」；副文「这可能是下面几种，请打开图鉴再看一眼，不要只信我。」

### 9.1 发起

`POST /ai/species-guess`  
游客。消耗配额。若正在观潮，前端会把候选生物写入该次观潮。

```json
{
  "uploadId": "up_10086",
  "spotId": "spot_qd_shilaoren",
  "tideHeightM": 0.8,
  "tideTrend": "falling",
  "clientTime": "2026-09-08T09:10:00+08:00",
  "sessionId": "watch_1001"
}
```

`sessionId` 可选，有则服务端也可把候选写入该观潮。

响应：`guessId`、`status`、`disclaimer`、`needHumanCheck`、`candidates[]`（`rank`、`speciesId`、`name`、`confidence`、`confidenceLabel`、`reason`、`wikiPath`）、`observeTip`、`safetyTip`、`unlockedMedalIds`。

规则：至少 2 个候选；不出现「已识别」；`confidence` 只排序；保护动物只给远看建议；审核失败不调模型；超时 `50003`。

### 9.2 查询 / 反馈

`GET /ai/species-guess/{guessId}`  
可选登录，仅本人或本 `clientId`。

`POST /ai/species-guess/{guessId}/feedback`  
可选登录。`pickedSpeciesId`、`helpful`。

## 10. 观潮记录

对应首页「开始观潮 / 观潮中 / 结束观潮」和「我的 → 观潮记录」。

一次观潮 = **起止时间 + 期间识别到的生物**。以文字为主，配系统卡通图，**用户不能上传照片**。不要再生成图鉴卡。

游客按 `X-Client-Id` 读写。登录后按用户，并合并该设备未登录记录。

### 10.1 开始

`POST /watch/sessions`  
游客。幂等。

```json
{
  "startedAt": "2026-09-08T16:01:00+08:00",
  "spotId": "spot_qd_shilaoren"
}
```

```json
{
  "id": "watch_1001",
  "startedAt": "2026-09-08T16:01:00+08:00",
  "spotId": "spot_qd_shilaoren",
  "species": []
}
```

同一设备同时只允许一条进行中的会话。重复开始返回已有会话，不要 409。

### 10.2 写入识别生物

`POST /watch/sessions/{id}/species`  
游客。仅进行中的会话。

```json
{
  "name": "藤壶",
  "time": "16:18",
  "speciesId": "sp_barnacle",
  "guessId": "guess_9001"
}
```

同名生物一次观潮只记一条。未在观潮中返回 `40901`。

### 10.3 结束

`POST /watch/sessions/{id}/end`  
游客。幂等。

```json
{
  "endedAt": "2026-09-08T16:40:00+08:00",
  "species": [
    { "name": "藤壶", "time": "16:18", "speciesId": "sp_barnacle" }
  ]
}
```

`species` 可空；服务端以已写入的为准，请求体作补全。

```json
{
  "id": "watch_1001",
  "date": "2026-09-08",
  "startedAt": "2026-09-08T16:01:00+08:00",
  "endedAt": "2026-09-08T16:40:00+08:00",
  "startTime": "16:01",
  "endTime": "16:40",
  "durationText": "39 分钟",
  "spotName": "青岛 · 石老人",
  "species": [{ "name": "藤壶", "time": "16:18", "speciesId": "sp_barnacle" }],
  "summary": "这次观潮从 16:01 到 16:40，一共 39 分钟。期间认出了 1 种潮间带伙伴：藤壶。",
  "mascotKey": "crab-star",
  "unlockedMedalIds": []
}
```

`summary` 由服务端生成短句，不要长文。`mascotKey` 只允许系统内置卡通，禁止用户图。

### 10.4 列表

`GET /watch/records`  
游客。Query：`page`、`pageSize`

按 `endedAt` 倒序。前端会再按 `date` 分组。字段同 10.3。进行中的会话不要出现在列表里。

### 10.5 详情

`GET /watch/records/{id}`  
游客（仅本人或本设备）。

## 11. 点亮地图

对应成就「继续探索」。底图是运营配置的示意图（可换），上覆迷雾区块。用户**定位经纬度**落入区块 bbox 后点亮，带消散动画。

不要再用 IP。不要在页面展示 IP、探索度文案、区块清单。右上角换地图。

精确经纬度**只用于当次匹配**，服务端只存 `mapId + regionId`，日志不要把经纬度与用户 ID 写在同一行。

`GET /light-maps`

```json
  ]
}
```

### 11.2 地图详情

`GET /light-maps/{mapId}`  
游客。登录时带上已点亮的 `lit`。

```json
{
  "id": "qingdao",
  "name": "青岛海岸",
  "mapUrl": "https://cdn.example.com/maps/qingdao.png",
  "regions": [
    {
```

`left/top/width/height` 为相对底图的百分比，供迷雾格子排版。bbox 是 GCJ-02。后续只改数据即可换图、换范围。

`GET /light-maps/{mapId}/progress`

### 13.4 研学报到签到

`POST /records/checkin`  
游客可调（身份由表单自带，不依赖账号）。

```json
{
  "name": "谢小主",
  "studentNo": "2026090101",
  "lat": 36.093,
  "lng": 120.477,
  "checkinAt": "2026-09-13T10:00:00+08:00"
}
```

口径：

1. `lat` / `lng` 为 GCJ-02，前端已按约 0.003°（≈300 米）网格取整，服务端只存网格值，不要回存或拼接精确轨迹；

3. 同一 `X-Client-Id`（或登录用户）同一天重复提交，建议幂等返回首次结果，不要 `409`；
4. 响应返回签到结果即可，如 `{ "ok": true }` 或签到记录对象；失败走统一错误码。

配套统计 `GET /records/checkins` 保持不变（登录）。

## 16. 数据与安全

1. 照片默认私有；识别图过内容安全。  
2. 删除 EXIF。点亮地图的经纬度只用于匹配，不入库、不与用户 ID 同日志行。  
3. AI 输入白名单：照片、点位名、城市、潮汐、天气。禁止学校、班级、真实姓名、手机号、住址。  
4. 物种结果是 `candidates[]`，不是「鉴定」。  
5. 潮汐/天气失败要降级，不阻断首页。  
6. 观潮记录禁止用户上传图；卡通图只用内置 key。  
7. 社区、图鉴卡分享链路已下线。  
8. 点亮地图底图为运营示意图，不是腾讯底图瓦片，不涉及审图号；§14 原生地图仍须露出 Logo / 审图号。
