# 观潮小程序接口文档

> 版本：V1.0  
> 日期：2026-08-26  
> 适用：微信小程序「观潮」演示功能落地 + 三项 AI 能力  
> 原则：游客可浏览公开内容；登录后才可上传、识别、生成图鉴卡、发布社区笔记、写入记录。

---

## 1. 约定

### 1.1 环境


| 环境  | Base URL（示例）                         |
| --- | ------------------------------------ |
| 开发  | `https://dev-api.example.com/api/v1` |
| 预发布 | `https://pre-api.example.com/api/v1` |
| 生产  | `https://api.example.com/api/v1`     |


合法域名需在小程序后台配置。生产环境禁止 IP / localhost。

### 1.2 请求头

```http
Content-Type: application/json
Authorization: Bearer <accessToken>
X-Request-Id: <uuid>
```

游客请求可不带 `Authorization`。上传、识别、生成卡片、打卡、收藏、进度写入、发布/互动社区笔记必须登录。

### 1.3 统一响应

成功：

```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "requestId": "b6c1e2f0-8a11-4c22-9d33-111111111111"
}
```

失败：

```json
{
  "code": 40001,
  "message": "参数不完整",
  "data": null,
  "requestId": "b6c1e2f0-8a11-4c22-9d33-111111111111"
}
```

分页：

```json
{
  "list": [],
  "page": 1,
  "pageSize": 20,
  "total": 0
}
```

时间一律 ISO 8601，时区 `Asia/Shanghai`，例如 `2026-08-26T09:04:00+08:00`。

### 1.4 鉴权


| 标记   | 含义                   |
| ---- | -------------------- |
| 游客   | 可不登录                 |
| 登录   | 必须有效 `accessToken`   |
| 可选登录 | 登录后返回个性化字段，未登录返回公开字段 |


Token 建议 2 小时过期，用 `refreshToken` 续期。微信 `code` 只允许后端换 `openid`，密钥不得下发小程序。

### 1.5 错误码


| code  | HTTP | 含义                |
| ----- | ---- | ----------------- |
| 0     | 200  | 成功                |
| 40001 | 400  | 参数错误              |
| 40002 | 400  | 文件类型/大小不合法        |
| 40101 | 401  | 未登录或 token 失效     |
| 40301 | 403  | 未完成监护人同意          |
| 40302 | 403  | 无权访问该资源           |
| 40401 | 404  | 资源不存在             |
| 40901 | 409  | 重复提交（幂等冲突以外的业务冲突） |
| 42901 | 429  | 触发限流              |
| 50001 | 500  | 服务器内部错误           |
| 50002 | 503  | 第三方潮汐/天气超时，已降级    |
| 50003 | 503  | AI 服务不可用          |
| 50004 | 422  | 内容安全未通过           |


幂等：写接口支持 `Idempotency-Key`。相同 key 在 10 分钟内返回首次结果，不重复计费、不重复建卡。

### 1.6 限流（建议）


| 能力       | 未登录        | 已登录            |
| -------- | ---------- | -------------- |
| 读接口      | 60 次/分钟/IP | 120 次/分钟/用户    |
| 上传凭证     | —          | 20 次/小时/用户     |
| AI 物种猜测  | —          | 8 次/天/用户       |
| AI 潮汐建议  | 走首页缓存      | 首页 1 次/5 分钟/地点 |
| AI 图鉴卡生成 | —          | 5 次/天/用户       |
| 社区发布     | —          | 10 次/天/用户      |
| 社区评论     | —          | 60 次/小时/用户    |


超限返回 `42901`，`Retry-After` 为秒。

## 2. 现有功能对照

当前小程序四个 Tab 对应的接口如下。


| 页面  | 现有 UI                  | 接口                                                |
| --- | ---------------------- | ------------------------------------------------- |
| 首页  | 地点、搜索、今日潮汐、快捷入口、科普闯关   | `/home/today`、`/spots`、`/encyclopedia`、`/quizzes` |
| 社区  | 瀑布流笔记、话题、搜索、关注、点赞收藏评论、发布 | `/community/*` |
| 成就  | 完成度、勋章墙、弹窗、分享、排行       | `/achievements/overview`、`/medals`、`/share/medal` |
| 我的  | 资料、打卡/获赞/收藏/粉丝、观潮记录、设置 | `/me`、`/records`、`/privacy`、`/community/me/*` |


三项 AI 能力挂在现有链路上，不新开独立 Tab：

1. **AI 物种猜测**：首页「海洋图鉴」或观察拍照入口 → `/ai/species-guess`
2. **潮汐出门建议**：替换首页「潮高约 0.8m」→ `/home/today.advice`
3. **图鉴卡**：拍照观察后生成 → `/cards`

## 4. 首页与潮汐出门建议

首页一次拉取地点、潮汐原始数据、**AI 出门建议**、快捷入口状态。

### 4.1 今日首页

`GET /home/today`  
可选登录。

Query：


| 参数     | 类型     | 必填  | 说明                |
| ------ | ------ | --- | ----------------- |
| city   | string | 否   | 城市名，默认用户上次选择      |
| spotId | string | 否   | 赶海点 ID，优先于 city   |
| lat    | number | 否   | 仅当用户主动授权定位后上传     |
| lng    | number | 否   | 同上                |
| date   | string | 否   | `YYYY-MM-DD`，默认当天 |


不要在进入首页时自动定位。用户点「查看附近」后再带 `lat/lng`。

`trend` 枚举：`rising` | `falling` | `high` | `low` | `unknown`。

**AI 规则（潮汐建议）：**

- 输入只允许：潮汐点、天气、点位适龄/安全字段、当前时间。禁止把用户姓名、学校、精确住址送入模型。
- 输出必须是结构化字段，前端拼页面，不直接渲染模型长文。
- 模型失败时 `fallback=true`，用规则模板生成，例如：「当前潮高 {n} 米，{退潮/涨潮}，请关注下一变化时间 {t}。」
- 文案语气面向小学中高年级，短句，不恐吓，不鼓励冒险。
- 任何建议都带 `disclaimer`。不得出现「绝对安全」「保证适合赶海」。

## 8. 上传

拍照识别、观察记录、图鉴卡都先走同一套上传。用户点击后才调相机/相册。

### 8.1 申请上传凭证

`POST /uploads/credential`  
登录。

```json
{
  "scene": "speciesGuess",
  "contentType": "image/jpeg",
  "ext": "jpg"
}
```

`scene`：`speciesGuess` | `observation` | `card`

响应：

```json
{
  "uploadId": "up_10086",
  "objectKey": "private/u_10001/2026/08/26/up_10086.jpg",
  "host": "https://cos.ap-guangzhou.myqcloud.com",
  "headers": {
    "Authorization": "COS 签名",
    "Content-Type": "image/jpeg"
  },
  "expiresIn": 300
}
```

限制：jpg/png/webp，单张 ≤ 5MB，客户端优先压缩图。服务端去掉 EXIF。对象私有，只存 `objectKey`。

### 8.2 确认上传完成

`POST /uploads/{uploadId}/complete`  
登录。

触发压缩、去 EXIF、内容安全检测。未通过返回 `50004`。

```json
{
  "uploadId": "up_10086",
  "status": "approved",
  "width": 1280,
  "height": 960
}
```

`status`：`processing` | `approved` | `rejected`

## 9. AI 物种猜测

产品口径：**猜测 + 图鉴对照**，禁止「已识别为某某」。

前端固定文案示例：

- 标题：小螃蟹猜一猜
- 副文：这可能是下面几种，请打开图鉴再看一眼，不要只信我。
- 禁止：已识别、确认是、鉴定结果、100%



### 9.1 发起猜测

`POST /ai/species-guess`  
登录。消耗每日配额。

```json
{
  "uploadId": "up_10086",
  "spotId": "spot_qd_shilaoren",
  "tideHeightM": 0.8,
  "tideTrend": "falling",
  "clientTime": "2026-08-26T09:10:00+08:00"
}
```

`spotId`、潮汐字段可选，有助于把候选限制在当地潮间带常见种。

响应：

```json
{
  "guessId": "guess_9001",
  "status": "done",
  "disclaimer": "这是学习提示，不是物种鉴定。请对照图鉴，不要采集、不要伤害生物。",
  "needHumanCheck": true,
  "candidates": [
    {
      "rank": 1,
      "speciesId": "sp_barnacle",
      "name": "藤壶",
      "confidence": 0.62,
      "confidenceLabel": "比较像",
      "reason": "照片里有成片贴在礁石上的灰白小壳。",
      "wikiPath": "/encyclopedia/sp_barnacle"
    },
    {
      "rank": 2,
      "speciesId": "sp_oyster",
      "name": "牡蛎",
      "confidence": 0.28,
      "confidenceLabel": "也有可能",
      "reason": "壳更不规则，有时和藤壶长在一起。",
      "wikiPath": "/encyclopedia/sp_oyster"
    },
    {
      "rank": 3,
      "speciesId": null,
      "name": "我还不确定",
      "confidence": 0.10,
      "confidenceLabel": "建议对照图鉴",
      "reason": "角度较远或反光较强，需要再拍一张近照。",
      "wikiPath": null
    }
  ],
  "observeTip": "下次可以再靠近一点，把生物和旁边的石头一起拍进画面。",
  "safetyTip": "礁石湿滑，拍照时站稳；不要把生物抠下来。"
}
```

规则：

1. 至少返回 2 个候选；最高置信度也不得输出「已识别」。
2. `confidence` 仅供排序，前端展示 `confidenceLabel`：比较像 / 也有可能 / 不太像 / 建议对照图鉴。
3. `confidence < 0.35` 时，第一条候选名称改为「还看不太清」，并引导重拍。
4. 候选必须能关联本站图鉴；无法匹配时 `speciesId=null`，不编造学名。
5. 保护动物只给「请远远看看」+ 图鉴链接，不给采集建议。
6. 图片审核失败不调用模型。
7. 异步可选：先返回 `status=processing`，再用 `GET /ai/species-guess/{guessId}` 轮询。首版同步超时 8 秒，超时 `50003` 并提示「小螃蟹这会儿有点忙」。



### 9.2 查询猜测

`GET /ai/species-guess/{guessId}`  
登录，仅本人。

## 10. 观潮记录与图鉴卡

对应「我的观潮记录」。一张图鉴卡 = 一次完整观察成果。

生成输入：**照片 + 地点 + 时间 + 潮汐**。  
生成输出：**标题、三句观察、安全提醒**。可收藏、可分享、可点亮勋章。

### 10.1 生成图鉴卡

`POST /cards`  
登录。幂等。消耗每日配额。

```json
{
  "uploadId": "up_10086",
  "spotId": "spot_qd_shilaoren",
  "observedAt": "2026-08-26T09:12:00+08:00",
  "guessId": "guess_9001",
  "userNote": "石头缝里有好多小白点"
}
```

`guessId`、`userNote` 可选。有猜测结果时，卡片只写「可能是」，不写「已发现某某物种」。

响应：

```json
{
  "id": "card_7001",
  "status": "done",
  "shareEnabled": false,
  "coverUrl": "https://cdn.example.com/sign/...",
  "spotName": "青岛 · 石老人",
  "observedAt": "2026-08-26T09:12:00+08:00",
  "tideLine": "潮高约 0.8 米 · 退潮中",
  "title": "礁石上的小房子",
  "observations": [
    "退潮后，灰色小壳成片贴在潮湿的石头上。",
    "靠近看能发现它们一簇一簇挤在一起。",
    "今天风不大，适合站在安全的礁石边观察。"
  ],
  "safetyTip": "礁石湿滑，请和大人在一起，涨潮前离开水边。",
```

`relatedSpecies.relation`：`possible` | `mentioned`。禁止 `identified`。

**生成规则：**

- 标题 ≤ 12 字，童趣，不出现拉丁学名。

- 默认 `shareEnabled=false`。公开分享前需内容安全通过；未成年人作品默认仅自己可见。
- 失败时可用模板卡：`今日观潮` + 地点 + 时间 + 「拍到了潮间带的小发现，去图鉴里对照一下吧。」仍保存照片，不丢记录。

### 11.4a 待展示的新解锁

`GET /achievements/pending-unlocks`  
登录。返回「已结算解锁、但用户还没看过祝贺弹窗」的勋章。用于写接口当时没弹出来、或用户杀掉小程序后补弹。

```json
{
  "list": [
    {
      "medalId": "medal_2",
      "title": "探索新手",
      "displayTitle": "探索新手",
      "description": "地图上的空白正在减少，小小探索家开始熟悉海岸的模样。",
      "iconUrl": "https://cdn.example.com/badges/crab-map.png",
      "rarity": "rare",
      "source": "checkin",
      "unlockedAt": "2026-08-26T10:12:00+08:00"
    }
  ]
}
```

`source`：`quiz` | `card` | `guess` | `community` | `checkin` | `other`

没有待展示时返回空列表，不要 404。

### 11.4b 解锁回执（告诉后端用户已看到）

`POST /medals/{medalId}/unlock-ack`  
登录。幂等。

前端在弹出「恭喜解锁」烟花祝贺时立刻调用，告知后端：这条解锁已经展示过。同一勋章重复 ack 返回当前状态，不重复发奖。

```json
{
  "source": "quiz",
  "clientTime": "2026-08-26T10:12:05+08:00"
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| source | 否 | 与 11.4a 相同；写接口带回的解锁用对应来源，补弹用 `pending` |
| clientTime | 否 | 客户端弹出时间 |

响应：

```json
{
  "medalId": "medal_2",
  "acked": true,
  "alreadyAcked": false,
  "rewards": {
    "star": 300,
    "shell": 1
  }
}
```

未解锁该勋章返回 `40401`。未登录返回 `40101`。

前端约定：写接口（闯关 / 图鉴卡 / 社区笔记等）若返回 `unlockedMedalIds`，先弹祝贺并 ack；进入任一 Tab 再拉一次 `pending-unlocks`，避免漏弹。

## 13. 社区（观察笔记）

对应底部 Tab「社区」，形态对标常见图文社区：双列瀑布流、话题筛选、搜索、关注、点赞 / 收藏 / 评论、发布笔记。内容只做「安全观察分享」，不是物种鉴定，不做私信、直播、带货。

### 13.1 产品边界

- 游客可浏览推荐流、公开笔记、公开评论。

## 15. 场地探索（迷雾地图）

对应点位详情「开始探索」。底图只用微信原生 `map`（腾讯地图），不缓存、不导出瓦片。精确经纬度只留在手机内存，结束后删除，只上传网格。

### 15.1 场地配置

`GET /explore/venues/{venueId}`  
游客。`venueId` 可与 `spotId` 相同。

```json
{
  "venueId": "spot_qd_shilaoren",
  "name": "青岛 · 石老人",
  "city": "青岛",
  "center": { "latitude": 36.0932, "longitude": 120.4768 },
  "bbox": {
    "minLat": 36.0880,
    "minLng": 120.4680,
    "maxLat": 36.0990,
    "maxLng": 120.4880
  },
  "gridSizeM": 40,
  "scale": 16,
  "needGuardian": true
}
```

`gridSizeM` 由服务端定，客户端按同一公式把点打成 `venueId:row:col`。

### 15.2 开始探索（不下发定位）

前端在用户点击「开始探索」之前，不得调用 `wx.getLocation` / `wx.onLocationChange`。  
儿童账号若 `GET /me` 的 `needGuardianConsent=true`，只允许家长在设置里同意后再开定位；团体活动走 15.4。

### 15.3 提交探索结果

`POST /explore/sessions`  
登录。幂等。

**禁止**上传 `points`、`latitude`、`longitude`、轨迹图片。

```json
{
  "venueId": "spot_qd_shilaoren",
  "mode": "solo",
  "gridIds": ["spot_qd_shilaoren:3:7", "spot_qd_shilaoren:3:8"],
  "startedAt": "2026-08-30T16:01:00+08:00",
  "endedAt": "2026-08-30T16:28:00+08:00",
  "exploreRatio": 0.18
}
```

| 字段 | 说明 |
| --- | --- |
| mode | `solo` 个人定位；`group` 团体扫码，无轨迹 |
| gridIds | 经过的网格编号，去重 |
| startedAt / endedAt | 时长区间，不要秒级轨迹 |
| exploreRatio | `经过格数 / 场地总格数`，0～1 |

响应：

```json
{
  "sessionId": "exp_20260830_001",
  "venueName": "青岛 · 石老人",
  "exploreRatio": 0.18,
  "gridCount": 12,
  "badgeTitle": "潮间带初探",
  "unlockedMedalIds": []
}
```

### 15.4 团体二维码解锁

`POST /explore/qr-unlock`  
登录。儿童不必开定位。

```json
{ "code": "GC-CAMP-2026-081" }
```

响应带 `venueId`、`gridIds`（活动预置范围）、`exploreRatio`。前端按 15.3 `mode=group` 再提交一次会话，或服务端在本接口直接建会话。

### 15.5 分享卡

`GET /explore/sessions/{sessionId}/share`  
登录。只返回场地、徽章、探索比例，**不要路线点**。

```json
{
  "title": "我在青岛 · 石老人探索了 18%",
  "venueName": "青岛 · 石老人",
  "badgeTitle": "潮间带初探",
  "exploreRatio": 0.18,
  "path": "/pages/explore/explore?venueId=spot_qd_shilaoren"
}
```

## 16. 数据与安全要点

1. 照片默认私有；图鉴卡与社区笔记公开展示必须过内容安全。未成年人社区笔记默认 `reviewing`。
2. 删除 EXIF，日志不把精确经纬度与用户 ID 写在同一行。
3. AI 输入白名单：照片、点位名称、城市、潮汐、天气、用户一句观察。禁止学校、班级、真实姓名、手机号、家庭住址。
4. 所有 AI 响应带 `disclaimer`。物种结果是 `candidates[]`，不是 `species`。
5. 潮汐/天气第三方失败时降级，不阻断首页。
6. 管理后台需能抽查猜测与卡片，错误科普可下架。
7. 对象存储只存 key；详情接口返回短时签名 URL。
8. 社区不做私信；评论禁止联系方式；后台需能下架错误科普笔记。
9. 场地探索：不缓存/导出腾讯底图瓦片；不上传原始经纬度；迷雾和按钮不得遮挡地图 Logo、来源与审图号；儿童定位须家长开启。
