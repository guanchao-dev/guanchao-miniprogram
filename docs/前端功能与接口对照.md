# 寻潮记前端：功能与接口对照

> 对照文档：`docs/观潮小程序接口文档.md` V1.1  
> 游客主路径必须可走通；后端未就绪时前端用本地兜底，不要挡住浏览。

## 鉴权怎么发

- 所有请求带 `X-Client-Id`（本地生成）。  
- 有 token 就带 `Authorization`。  
- 标了「游客」的接口：**缺 token 不得 401**。  
- 前端读接口失败时用本地/演示数据，不把游客踢去登录页。

## 页面对照

| 页面 | 游客 | 调用 | 无后端时 |
| --- | --- | --- | --- |
| 首页 | 是 | `GET /home/today`、`GET /spots` | 地点写青岛；推荐用 `utils/spotGuide.ts` |
| 开始/结束观潮 | 是 | `POST /watch/sessions`、`.../end`、`.../species` | `utils/watchLog.ts` 本地存 |
| 拍照识别 | 是（配额更严） | 上传 + `POST /ai/species-guess` | 失败提示；不跳登录，除非接口明确 401 |
| 出门建议 | 是 | `POST /ai/tide-advice` | 弹窗失败 toast |
| 赶海点全部 | 是 | `GET /spots`、`GET /spots/{id}`、`GET /home/today` | 本地目录 |
| 潮汐表 | 是 | `GET /home/today`、`GET /spots` | `DEMO_TIDE_POINTS` |
| 潮汐日历 | 是 | `GET /tide/calendar` | `demoCalendarDays` |
| 图鉴 / 详情 | 是 | `GET /encyclopedia`、`GET /encyclopedia/{id}` | `utils/demoContent.ts` |
| 知识科普 | 是 | `GET /knowledge`、`GET /knowledge/{id}` | `utils/knowledge.ts` |
| 搜索 | 是 | `GET /search` 或 spots+encyclopedia `keyword` | 空结果 |
| 成就 | 是 | `GET /achievements/overview`、`GET /medals`、`GET /medals/{id}` | 空进度+锁定墙 |
| 排行榜 | 是 | `GET /achievements/leaderboard` | 本地演示榜 |
| 点亮地图 | 是 | `GET /light-maps`、`GET /light-maps/{id}`、`POST .../visits`、`GET .../progress` | `utils/lightMap.ts` |
| 观潮记录 | 是 | `GET /watch/records` | 本地 `watchLogs` |
| 装备 | 是 | `GET /gear` | 本地演示清单 |
| 帮助 | 是 | `GET /help/faq`；反馈要登录 | 本地 FAQ |
| 登录 / 我的 | 登录后 | `POST /auth/wechat-login`、`GET /me` | 未登录显示「点击登录」 |

## 不要再调

- `/community/*`  
- 用 `/cards` 当观潮记录  
- 用 IP 点亮地图  

## 登录后多做的事

服务端用 `clientId` 合并：观潮记录、点亮区块、识别次数。前端不必自己迁数据。
