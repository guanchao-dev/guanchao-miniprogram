# 「海大观潮」项目介绍 PPT 大纲

## P1 封面

- 主标题：海大观潮 · 海洋素养数智平台
- 副标题：让每个人安全、有趣地亲近海洋
- 团队名 + 日期；背景用小程序界面或赶海场景图

## P2 目录

- 背景痛点 / 解决方案 / 技术实现 / 团队 / 成果与合作 / 商业模式 / 未来规划

## P3 背景与痛点

- 国家战略：海洋强国 + 联合国「海洋十年」海洋素养提升行动
- 大众热潮：赶海话题浏览量超百亿，持续破圈
- 三大痛点：潮汐数据难懂、缺乏安全预警、游玩体验同质化
- 备注：现有工具两极分化——专业 App 太硬核、内容社区碎片化

## P4 解决方案总览

- 一句话定位：潮汐预测 + 赶海安全 + 生物图鉴 + 海洋素养课程，整合于一个微信小程序
- 四大模块四宫格展示（各配图标）
- 备注：微信生态免下载，获客成本极低

## P5 功能一：潮汐预测与安全预警

- 潮汐调和分析降维 → 直观「出行雷达」
- 独创防涨潮被困撤离倒计时
- 潮汐日历 + 天气 + AI 出行建议

## P6 功能二：AI 海洋生物图鉴

- 拍照 → AI 识别（通义千问视觉大模型）→ 生成专属图鉴卡
- 物种科普 + 收藏 + 分享
- 备注：核心闭环——拍摄、识别、集卡、点亮勋章

## P7 功能三：游戏化成长体系

- LBS 打卡、成就勋章墙、闯关答题、排行分享
- 高频情绪价值颠覆低频工具属性

## P8 功能四：海洋素养课程

- 闯关式科普课程 + 安全知识问答
- 面向中小学场景的数字海洋科普内容

## P9 技术架构与完成度

- 前端：微信小程序原生 + TypeScript
- 后端：FastAPI + MySQL + Redis + 通义千问（文本 qwen-plus / 视觉 qwen-vl-max）
- 已落地 50 个接口，核心业务闭环全通
- 备注：诚实展示——演示版可用，真实潮汐数据源接入为下一步重点

## P10 三大创新点

- 学术创新：潮汐调和分析 + 气压风浪数据 → 安全撤离倒计时
- 模式创新：LBS + RPG，线下赶海变线上收集探索
- 技术创新：AI 视觉识别 + AI 建议真实在跑

## P11 团队

- 9 人跨学科团队：海洋科学、环境科学、公共管理、设计
- 创始人统筹：产品定位、商业模式、外部沟通
- 指导教师余静教授（海洋与大气学院博导，海洋工程科学技术奖一等奖）

## P12 发展历程（时间线）

- 上海社区 + 涠洲岛科普实践，收集一线反馈迭代
