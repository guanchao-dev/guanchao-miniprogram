# 图片资源接入说明（前端必读）

> 日期：2026-09-11  
> 背景：小程序主包超过 2MB 上限，**所有本地图片已迁到服务器**，需要前端改成从服务器加载。  
> 后端已经全部部署好了，前端只需按本文改**引用方式**。

---

## 一、一句话规则

把代码里所有 `/assets/xxx` 替换成：

```
https://www.blueakaiwu.cn/api/v1/static/assets/xxx
```

**唯一例外**：`app.json` 里 tabBar 的 `iconPath` / `selectedIconPath` **不能改**（原因见 §5）。

### 替换示例

| 原来（本地） | 改成（服务器） |
| --- | --- |
| `/assets/home/home-fish.png` | `https://www.blueakaiwu.cn/api/v1/static/assets/home/home-fish.png` |
| `/assets/badges/crab-cloud.png` | `https://www.blueakaiwu.cn/api/v1/static/assets/badges/crab-cloud.png` |
| `/assets/maps/coast-map.jpg` | `https://www.blueakaiwu.cn/api/v1/static/assets/maps/coast-map.jpg` |

---

## 二、Base URL

```
https://www.blueakaiwu.cn/api/v1
```

**注意**：必须是带 `www` 的域名。微信不支持父域名，`blueakaiwu.cn` 和 `www.blueakaiwu.cn` 是两个独立域名。

## 三、静态图片接口

### `GET /static/{路径}`

| 项 | 说明 |
| --- | --- |
| 鉴权 | **不需要**（游客可直接访问） |
| 请求方式 | GET |
| 响应 | 图片二进制（`image/png` / `image/jpeg`） |
| 缓存 | 响应头带 `Cache-Control: public, max-age=86400`（缓存 1 天） |

**URL 规则**：`{路径}` 就是原来 `/assets/` 后面的部分，原样拼上去即可。

```
本地路径                              →  服务器 URL
/assets/home/home-fish.png           →  {BASE}/static/assets/home/home-fish.png
/assets/badges/crab-cloud.png        →  {BASE}/static/assets/badges/crab-cloud.png
```

### 在小程序里怎么用

**方式 A：`<image>` 直接写完整 URL（推荐，最省事）**

```xml
<image src="https://www.blueakaiwu.cn/api/v1/static/assets/home/home-fish.png" mode="aspectFit" />
```

**方式 B：JS 里拼**

```js
const BASE = 'https://www.blueakaiwu.cn/api/v1'

// 本地路径转服务器地址
function asset(path) {
  if (!path) return ''
  if (/^https?:\/\//.test(path)) return path   // 已经是完整地址
  return BASE + '/static' + path               // '/assets/x' -> BASE/static/assets/x
}
```

**方式 C：先下载成临时文件再显示**（如果遇到域名/渲染问题时的兜底）

```js
wx.downloadFile({
  url: 'https://www.blueakaiwu.cn/api/v1/static/assets/home/home-fish.png',
  success: (res) => { if (res.statusCode === 200) this.setData({ src: res.tempFilePath }) }
})
```

> 三种方式都行。正常情况下**方式 A** 最简单，微信会自动缓存。

## 四、其他图片接口

除了静态图，这些是**运行时生成**的图片（用户上传、图鉴封面等）：

| 用途 | 接口 | 鉴权 |
| --- | --- | --- |
| 用户上传的图（识别/图鉴卡等） | `GET /uploads/{uploadId}/content` | 不需要 |
| 官方图鉴封面 | `GET /encyclopedia/{speciesId}/cover` | 不需要 |
| 用户头像 | `GET /users/{userId}/avatar` | 不需要 |
| 用户上传到图鉴的照片 | `GET /encyclopedia/{speciesId}/photos/{photoId}/content` | 不需要 |

**这些接口返回的都是相对路径**，前端需要自己拼 Base URL：

| 接口返回 | 前端拼成 |
| --- | --- |
| `"/uploads/up_xxx/content"` | `https://www.blueakaiwu.cn/api/v1/uploads/up_xxx/content` |
| `"/encyclopedia/sp_barnacle/cover"` | `https://www.blueakaiwu.cn/api/v1/encyclopedia/sp_barnacle/cover` |
| `"/users/u_xxx/avatar"` | `https://www.blueakaiwu.cn/api/v1/users/u_xxx/avatar` |

示例：`GET /community/feed` 返回的 `coverUrl` 是 `"/uploads/up_xxx/content"`，前端要拼上 Base URL 才能用。

## 五、两个**不能**搬到服务器的例外

### 1. tabBar 图标（微信硬性要求）

`app.json` 里的 `tabBar.list[].iconPath` / `selectedIconPath` **必须是包内本地文件**，微信不支持网络图片。

```json
{
  "tabBar": {
    "list": [
      {
        "pagePath": "pages/home/home",
        "text": "首页",
        "iconPath": "assets/tab/home.png",          // ← 保持本地，不要改
        "selectedIconPath": "assets/tab/home-active.png"
      }
    ]
  }
}
```

这 6 个图标（3 个 tab × 2 态）**保留在 `assets/tab/` 目录里**，不要删。

### 2. wxss 里的 `background-image`

**wxss 的 `background-image` 不支持网络图片**，只能用本地路径或 base64。

当前项目**没有**用到（已检查过），但以后如果要加，记得这点。

## 七、必须配套的后台配置

### 小程序后台 → 开发 → 开发管理 → 开发设置 → 服务器域名

**三个分类都要填**，每一项都填：

```
https://www.blueakaiwu.cn
```

| 分类 | 用途 |
| --- | --- |
| **request 合法域名** | 所有 API 接口 |
| **uploadFile 合法域名** | 上传照片、头像 |
| **downloadFile 合法域名** | **所有图片**（缺这个图片全裂） |

⚠️ 三个坑：
1. **必须带 `www`**
2. **不要带端口、不要带路径**（不能写 `:443` 或 `/api/v1`）
3. 三个分类**分开填**，只填一个不算数

## 八、常见问题

### Q：图片不显示？

按顺序排查：

1. **downloadFile 合法域名配了吗？**（`https://www.blueakaiwu.cn`）—— 这是最常见的原因
2. **URL 拼对了吗？** 浏览器/工具里直接打开图片 URL，看能不能出图
3. **是不是本地缓存？** 删除小程序 → 清微信缓存 → 重进
4. **别用「调试模式」验证** —— 调试模式会跳过域名校验，会掩盖真实问题。测完记得关掉调试模式再验一次

### Q：为什么有的图能显示、有的不能？

检查那些图是不是还在用**本地相对路径**（`/assets/...`）。本项目里所有 `/assets/` 引用都应该已经改成完整 URL 了。

### Q：打包时报「图片和音频资源大小应不超过 200K」？

说明还有大图在包里。跑一下项目里的 `tools/externalize_assets.py` 检查有没有漏改的引用。

## 九、前端重新发版时注意

如果前端代码被重新生成/覆盖，以下**要重新应用**（项目 `tools/` 里有现成脚本）：

```bash
# 在「前端」目录下执行，把 /assets/ 引用批量替换成服务器地址
python tools/externalize_assets.py
```

另外这几项配置**不要被覆盖**：

- `config/env.ts` 里的 `BASE_URL = 'https://www.blueakaiwu.cn/api/v1'`
- `app.json` 里的 `"lazyCodeLoading": "requiredComponents"`
- `project.config.json` 里的 `packOptions.ignore`（要忽略 `assets/` 下的各子目录、`.git`、`docs`、`resources`、`tools`）
- 各个页面 `.json` 里的 `usingComponents`（`unlock-popup` 必须在用到它的页面里声明，见下）

> **关于 `usingComponents`**：`lazyCodeLoading: requiredComponents` 开启后，只依赖 `app.json` 全局声明的组件**在某些基础库版本上不会被注入**，页面会白屏。  
> 用到 `<unlock-popup>` 的页面（home / achieve / profile / discover / explore / quiz）必须在自己的 `.json` 里声明：
> ```json
> {
>   "usingComponents": {
>     "unlock-popup": "/components/unlock-popup/unlock-popup"
>   }
> }
> ```

## 十、快速自测

改完后，用浏览器或 curl 验证图片能访问：

```
https://www.blueakaiwu.cn/api/v1/static/assets/home/home-fish.png
https://www.blueakaiwu.cn/api/v1/static/assets/badges/crab-cloud.png
https://www.blueakaiwu.cn/api/v1/static/assets/maps/coast-map.jpg
```

三个都返回图片 = 服务器侧没问题，剩下就是前端引用和域名白名单的事。
