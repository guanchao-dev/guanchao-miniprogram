## 一、成就解锁回执（P0）

结算逻辑已有。缺的是「弹过祝贺没有」。

### 1. `GET /achievements/pending-unlocks` — 登录

返回已解锁且未 ack 的勋章。没有则 `list: []`，不要 404。

```json
{
  "list": [
    {
      "medalId": "medal_2",
      "title": "探索新手",
      "displayTitle": "探索新手",
      "description": "地图上的空白正在减少。",
      "iconUrl": "",
      "rarity": "rare",
      "source": "checkin",
      "unlockedAt": "2026-08-26T10:12:00+08:00"
    }
  ]
}
```

`source`：`quiz` | `card` | `guess` | `community` | `checkin` | `other`

### 2. `POST /medals/{medalId}/unlock-ack` — 登录，幂等

弹窗出现时立刻打。重复 ack 返回当前状态，不重复发奖。

请求：`{ "source": "quiz", "clientTime": "2026-08-26T10:12:05+08:00" }`（均可选）  
响应：`{ "medalId", "acked": true, "alreadyAcked": false, "rewards": { "star", "shell" } }`  
未解锁该勋章：`40401`。

## 三、场地探索（P0）

精确经纬度只留在手机。后端**禁止**收 `points` / `latitude` / `longitude` / 轨迹图。

### 1. `GET /explore/venues/{venueId}` — 游客

`venueId` 可与 `spotId` 相同。没有该场地用石老人默认框也可以，但不要 5xx。

```json
{
  "venueId": "spot_qd_shilaoren",
  "name": "青岛 · 石老人",
  "city": "青岛",
  "center": { "latitude": 36.0932, "longitude": 120.4768 },
  "bbox": {
    "minLat": 36.088,
    "minLng": 120.468,
    "maxLat": 36.099,
    "maxLng": 120.488
  },
  "gridSizeM": 40,
  "scale": 16,
  "needGuardian": true
}
```

网格编号必须与前端同一公式（`gridSizeM` 由服务端定）：

```text
latM = 111320
lngM = 111320 * cos(中点纬度)
row  = floor( (lat - minLat) * latM / gridSizeM )
col  = floor( (lng - minLng) * lngM / gridSizeM )
id   = "{venueId}:{row}:{col}"
```



### 2. `POST /explore/sessions` — 登录，幂等

```json
{
  "venueId": "spot_qd_shilaoren",
  "mode": "solo",
  "gridIds": ["spot_qd_shilaoren:3:7", "spot_qd_shilaoren:3:8"],
  "startedAt": "2026-08-30T16:01:00+08:00",
  "endedAt": "2026-08-30T16:28:00+08:00",
  "exploreRatio": 0.18
}
```

`mode`：`solo` | `group`。`exploreRatio` 为 0～1。  
响应：`{ sessionId, venueName, exploreRatio, gridCount, badgeTitle, unlockedMedalIds }`

儿童 `GET /me.needGuardianConsent=true` 时，`solo` 可回 `40301`；`group` 不要求定位。

### 3. `POST /explore/qr-unlock` — 登录

请求：`{ "code": "GC-CAMP-2026-081" }`  
响应：`{ venueId, gridIds, exploreRatio, badgeTitle? }`  
无效码：`40401`。前端收到后再打一次 sessions（`mode=group`）；也可在本接口直接建会话，但 sessions 仍要能幂等。

### 4. `GET /explore/sessions/{sessionId}/share` — 登录

只返回场地、徽章、比例，不要路线。

```json
{
  "title": "我在青岛 · 石老人探索了 18%",
  "venueName": "青岛 · 石老人",
  "badgeTitle": "潮间带初探",
  "exploreRatio": 0.18,
  "path": "/pages/explore/explore?venueId=spot_qd_shilaoren"
}
```
