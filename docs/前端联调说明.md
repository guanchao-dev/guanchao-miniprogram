# 前端联调说明（发给后端）

小程序用 `wx.request` 封装成 `http.get / http.post / http.upload`。登录走后端已有的微信 `code2session`。

## 1. 启动前

1. 后端：`uvicorn app.main:app --reload`，确认 `http://127.0.0.1:8000/health`
2. 小程序：打开 `config/env.ts`，把 `BASE_URL` 改成后端地址
   - 开发者工具模拟器：`http://127.0.0.1:8000/api/v1`
   - 真机：`http://<电脑局域网IP>:8000/api/v1`
3. 开发者工具：详情 → 本地设置 → 勾选「不校验合法域名」
4. 小程序 AppID 需与后端 `.env` 里的 `WECHAT_APPID` 一致

## 2. 登录

「我的 → 登录 / 注册」进入登录页，点击「微信一键登录」：

```text
wx.login() 拿到 code
→ POST /api/v1/auth/wechat-login  { "code": "..." }
→ 保存 accessToken / refreshToken
```

必须在微信开发者工具里点登录，手动伪造 code 会被微信拒绝（40001，属正常）。

## 3. 上传约定

前端使用 `wx.uploadFile`：

- URL：`POST /api/v1/uploads`
- 文件字段名：`file`
- 表单字段：`scene` = `speciesGuess` | `observation` | `card`
- Header：`Authorization: Bearer <accessToken>`

请返回：

```json
{ "code": 0, "data": { "uploadId": "up_xxx", "status": "approved" } }
```

## 4. 建议联调顺序

1. `GET /health`
2. 微信登录 `POST /auth/wechat-login`
3. 首页 `GET /home/today`（游客也可）
4. 首页点「出门建议」→ `POST /ai/tide-advice`
5. 登录后点「拍一张猜一猜」→ 上传 → `POST /ai/species-guess`
6. 点「今日发现」进入独立页，填写照片/时间/潮汐/观察 → `POST /uploads` → `POST /cards`
7. 结果页可 `POST /cards/{id}/favorite`、`POST /cards/{id}/share`
8. 「我的观潮记录」→ `GET /cards`，点进详情 `GET /cards/{id}`
9. 「成就」→ `GET /achievements/overview`、`GET /medals`

首页「当前潮汐高度」用 `GET /home/today` 的 `tide.points` 画 canvas 曲线，不再使用装饰底图。

## 5. 前端请求头

```
Content-Type: application/json
Authorization: Bearer <accessToken>
X-Request-Id: <uuid>
Idempotency-Key: <写接口自动带>
```

40101 会自动用 `POST /auth/refresh` 续期。

## 6. 社区（后端未上线时前端用演示数据）

底部 Tab「社区」已按接口文档 §13 对接。后端还没有这些路径时，请求失败会回落到本地演示笔记，页面仍可点。

| 页面 | 接口 |
|---|---|
| 信息流 | `GET /community/topics`、`GET /community/feed` |
| 搜索 | `GET /community/search/hot`、`GET /community/search` |
| 详情 | `GET /community/notes/{id}`、评论 / 点赞 / 收藏 / 关注 |
| 发布 | `POST /uploads` `scene=community` → `POST /community/notes` |

## 7. 成就解锁祝贺

写接口若返回 `unlockedMedalIds`，或 Tab 打开时 `GET /achievements/pending-unlocks` 有数据，会弹出烟花祝贺（震动），并立刻 `POST /medals/{id}/unlock-ack` 告诉后端「用户已看到」。点「立即查看」进入成就页勋章详情。

## 8. 场地探索（腾讯地图）

1. 腾讯位置服务 Key 已写在 `config/env.ts` 的 `TENCENT_MAP_KEY`，探索页 `<map subkey>` 会带上。控制台须选「微信小程序」并绑定 AppID `wx6af244f2692b007f`
2. 小程序后台隐私指引声明：仅在用户点击「开始探索」后使用前台定位
3. 接口见文档 §15：`GET /explore/venues/{id}`、`POST /explore/sessions`、`POST /explore/qr-unlock`
4. 前端禁止上传经纬度；分享卡不含路线
5. 原生 `map` 底部不要盖按钮，以免挡住 Logo / 审图号
