- **技术栈**：FastAPI + SQLAlchemy 2.0 异步 + MySQL 8.4 + Redis 5.0.14 + 通义千问（DashScope）
- **AI 模型**：文本 `qwen-plus`、视觉 `qwen-vl-max`（OpenAI 兼容模式）
